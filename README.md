# Sistema de Gestión PROFEA

Aplicación multiusuario con **Supabase Auth + PostgreSQL** como backend permanente y única fuente de verdad de los datos de negocio.

La rama `feat/firebase-multiusuario` está en proceso de retirada de la capa de compatibilidad heredada. No debe incorporarse ningún flujo de sincronización manual ni persistencia de datos de negocio en Firebase o en `localStorage`.

## Producción

Aplicación pública: https://gestionprofea.vercel.app/
